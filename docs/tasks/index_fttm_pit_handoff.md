## 1. 权重来源盘点

本任务只把 `rawdata.index_weight` 作为官方指数历史权重源。该视图当前指向
Tushare 权重表，并同时保存 `index_code`、`con_code`、`trade_date`、`weight`。

另外两个本地来源不承担历史官方权重主源：

- `rawdata.index_stock_cons_weight_csindex` 有权重字段，但当前任务形态是指定指数的
  CSIndex 快照，不能在未证明历史连续性前替代 `rawdata.index_weight`。
- `rawdata.index_member_versioned` 保存 Tinysoft 成分进出事件，不含官方权重。

有效权重快照必须同时满足：

- `trade_date <= obs_date`，不得使用未来快照；
- 同一指数、同一 `trade_date` 的权重合计在 `[99, 101]`；
- 月末使用不晚于月末的最近有效快照；
- 最近有效快照距月末不得超过 65 天；全 A 总市值权重不得超过 31 天。

## 4. 计算合同

输入个股预测必须来自同一 `obs_date` 的 `pit.pit_stock_fttm_monthly`。对每个
`universe_code × org_name × obs_date`：

```text
normalized_weight_i = raw_weight_i / sum(raw_weight_j for covered stocks of the org)
org_universe_fttm = sum(normalized_weight_i * stock_fttm_np_i)
index_fttm_np = arithmetic_mean(org_universe_fttm across orgs)
```

即先在机构内部对该机构有覆盖的成分重新归一化，再对机构做算术平均。不得先对股票
做跨机构平均后再按指数权重聚合。

扩散度只比较同一对象、同一机构的相邻自然月：

```text
up_org_count = count(current_org_fttm > previous_org_fttm)
diffusion_up = up_org_count / matched_org_count
```

如果没有前月匹配机构，`diffusion_up` 必须为 `NULL`，不能填成 0 或 0.5。批次计算
必须额外读取前一自然月作为只读锚点。

## 5. 输出与调度

目标表：`pit.pit_index_fttm_monthly`

主键：

```text
(obs_date, universe_type, universe_code, weight_basis)
```

核心审计字段包括权重来源及日期、权重陈旧天数、结构/活跃/有权重/有预测成分数、
覆盖权重比例、机构数、相邻月匹配机构数、上涨机构数、扩散度、质量原因、个股 FTTM
公式版本和最大研报日期。

任务名：`pit_index_fttm_monthly`；调度别名：`index_fttm`；依赖：
`pit_stock_fttm_monthly`。

正式历史回填默认从 2014-01-31 开始；每个指数只从其首个有效权重月开始出数。增量
任务至少重算最近 8 个完整自然月，保证六个月研报窗口及相邻月扩散度的修订传播。
