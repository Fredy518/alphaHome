# 采集批次成功契约

生产采集脚本默认将本次发现并选择的所有任务视为必需输入。必需任务失败、部分成功、取消、未知状态、无理由的空数据或缺失结果时，整个批次退出码为 1；不再使用 80% 成功率阈值。只有带明确理由的 `expected_no_data` 可作为预期空数据通过。

经任务维护者明确认定的可选任务可用重复的 `--optional-task TASK_NAME` 声明。可选任务失败保留在 `batch_outcome.optional_failures` 中；错误名称、重复结果、缺失结果仍然阻断。该参数不证明下游所需输入齐全。

`--dry-run` 仅代表预览结果，不能证明数据新鲜度。采集批次成功后，PIT、Factors、Features 仍分别检查自己的输入与时点边界。
