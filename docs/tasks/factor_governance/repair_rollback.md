# 修复回滚的所有权协议

`repair_owner_v1` 记录每个日期的原批次、原数据校验和、原行版本、修复后的行版本，以及修复创建的周五约束 OID。修复持有会话级排他锁；普通快照写入和当前批次登记持有同一命名空间的事务级共享锁。

回滚在一个事务内先核对全部日期，再恢复数据、当前批次指针、修复状态和属于该次修复的约束。已有后续批次、行被另行改写、档案损坏或约束被重建时，整次回滚拒绝执行。已经回滚的记录重复调用返回 `already_rolled_back`。

旧修复记录没有这些所有权证据，自动回滚会明确拒绝，需要单独审阅恢复方案。禁止将拒绝解释为可以强制覆盖当前结果。

代码上线不等于执行历史修复。生产修复、恢复、约束变更仍按具体目标和计划单独授权。
