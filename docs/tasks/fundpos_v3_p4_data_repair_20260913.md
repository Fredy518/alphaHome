# fundpos v3 P4 数据补库记录（2026-09-13）

## 结论

P4 的市场因子和增强指数成分缺口可以通过 AlphaHome 补库解除；严格
历史合同仍需要带公告日、生效日、正文位置和文档哈希的合同证据，不能由
`fund_basic_ext` 当前文本单独替代。融资成本已取得满足 2022—2024 开发与
模型选择阶段的 DR007 缓存，但由于在线 Wind/iFinD API 不可用，该来源仍是
带版本哈希的条件证据。

本次没有开启 2025—2026 最终保留样本，也没有据此宣布模型通过。

## 已完成补库

### 固收总收益因子

在 `rawdata.index_performance` 中补入中证官网“利息再投资”指数：

| 资产 | 指数代码 | 指数口径 |
|---|---|---|
| `rate_short` | `N11099` | 中证短期国债指数（利息再投资） |
| `rate_long` | `N11075` | 中证长期国债指数（利息再投资） |
| `credit_short` | `N31199` | 中证 0—1 年中高等级信用债指数（利息再投资） |
| `credit_long` | `N31203` | 中证 7—10 年中高等级信用债指数（利息再投资） |
| `convertible_bond` | `N31078` | 中证可转债及可交换债指数（利息再投资） |

每条序列 1,219 行，覆盖 2021-09-01 至 2026-09-11；2021-09-01 至
2024-12-31 的 807 个 SSE 开市日均无缺口，收盘点位无空值或非正数。
官网 `change_pct` 与收盘点位计算的最大差异为 0.01 个百分点，属于官网
展示精度差异。

用户配置中的 `csindex_index_performance.index_codes` 已加入以上五个代码，
并保留既有 `H00922`，后续智能更新会继续维护六条序列。

### DR007 融资成本

新增采集任务 `excel_macro_dr007_history`，读取本地 iFinD 工作簿缓存中的
`L001619493`，写入 `excel.macro_dr007_history`，并暴露
`rawdata.macro_dr007_history`。

- 全历史缓存：2014-12-15 至 2025-05-27，2,799 行。
- P4 开发/选择期：2021-09-01 至 2024-12-31，覆盖 807/807 个沪深交易日。
- 保存原单元格、文件哈希、文件修改时间、指标编号和证据状态。
- 来源工作簿哈希已在用户配置中锁定；文件改变时任务会拒绝无审查覆盖。
- 工作簿中的周末缓存行保留作审计，模型必须按交易日历筛选。

本机 Wind Python 接口返回“无 Python API 权限”，天软普通行情接口也不能
读取该宏观序列。因此该表只作为有来源记录的历史缓存，不能描述为在线
Wind、iFinD 或 CFETS 实时源。与 2023-06 以后 FR007 的重叠对照也证实两者
口径差异明显，禁止拼接。

### 增强指数历史成分

补齐 `H30531.CSI` 的 Tushare 历史权重，并将以下六个试测指数回填到
`pit.pit_etf_index_members_monthly`：

`000300.SH`、`000905.SH`、`399006.SZ`、`399814.SZ`、
`000846.CSI`、`H30531.CSI`。

- 2021-09 至 2024-12：240/240 个“指数×月末”均成功，49,997 行。
- 2025-01 至 2026-08：120/120 个“指数×月末”均成功，24,997 行。
- 所有组合质量为 `high`、`is_eligible=true`，均来自官方指数权重，未使用
  ETF 披露持仓降级。
- 权重来源日在观察日之后的记录为 0；开发期最大陈旧度为 30 天。

`tushare_index_weight` 现在支持显式 `index_code/index_codes`，便于精确补库；
配置中的 `extra_index_codes` 会在原 ETF 指数全集之外追加
`000846.CSI`、`H30531.CSI`，避免日常维护遗漏。

`fund_basic_ext` 将 `000042.OF` 的目标指数记为 `000846.SH`，而官方历史
权重使用 `000846.CSI`。二者代码根相同且基金目标、基准文本均明确指向
中证财通可持续发展 100；下游应保留这条显式别名，不能按交易所后缀盲目
改写其他指数。

## 已核验但未改写的披露时点证据

110 只试测产品在 2021-09 至 2024-12 共 1,537 条季度财务记录，
`fund_financial_quarterly_ext.ann_date` 全部存在。与
`fund_portfolio` 同基金、同报告期匹配的 1,094 条记录中，公告日全部等于
该报告期持仓首次公告日；半年报和年报的分批披露仍保留其后续公告日。

同范围 `fund_asset_alloc` 也有 1,537 条记录，资产和净资产金额可用，但其
自身公告日为空。可在标准化证据层按“基金+报告期”连接季度财务公告日，
并把恢复方法和两张来源表同时记录；不应直接覆盖 Tinysoft 原始表，也不能
把首次公告日套给后续分批才披露的全部持仓。

## 仍未解除的严格条件

1. **历史合同**：110 只基金的 `fund_basic_ext.investment_scope` 均有文本，
   `latest_change_date` 也均不晚于 2024-06-29，但这是当前供应商快照，缺少
   正式文档哈希、公告日、生效日和原文位置。尤其该表的
   `latest_change_date` 是由成立、上市、清算等生命周期日期合成，并不证明
   合同或目标指数当时没有修订。它可作抽取交叉检查，不能单独解除
   `NO_VERIFIED_HISTORICAL_CONTRACTS`。
2. **增强指数目标历史**：20/20 只基金有当前目标指数，且目标、基准或投资
   目标文本能够互相印证；严格 PIT 身份仍应由当时合同/招募说明书或带版本
   的历史基金基本信息确认。研究阶段可标为条件证据，不能称为完整历史映射。
3. **融资结构**：资产配置可计算总资产/净资产杠杆，但 `repo_sold_value`
   全为零占位，不能把“总资产减净资产”全部解释成正回购。普通债券仓位仍应
   按融资信息完整度分别输出确认值、条件值或不可确认。

因此，P4 的五个固收因子与历史指数成分数据门槛已经具备；DR007 达到
2022—2024 条件验证要求。剩余核心工作是合同证据抽取和下游适配，不是继续
无边界扩充行情表。
