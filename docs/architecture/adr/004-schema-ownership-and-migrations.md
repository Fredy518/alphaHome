# ADR 004：Schema 所有权与显式迁移

状态：采纳。业务归属固定为 `pit`、`factors`、`features`；`pgs_factors` 是只读兼容接口。fundpos 使用自己冻结的软件包、运行时、配置和资源，根项目升级不得改变它的依赖或输入契约。

计划、审计预览、readiness 和上下文创建必须无隐式 DDL。缺表、缺列或结构漂移返回明确的迁移需求；普通任务不能通过自动建表掩盖问题。迁移命令与业务运行分开，准备 SQL、前置核验、回退和验收步骤后才执行明确授权的生产迁移。

本轮仅在隔离的本地测试数据库验证 DDL、约束和事务；生产授权、历史回补、权限调整、兼容视图只读化、凭据轮换、数据库服务升级及远程推送独立管理。代码通过测试不代表这些生产步骤已经完成。
