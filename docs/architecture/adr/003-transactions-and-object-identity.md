# ADR 003：提交边界、锁和对象身份

状态：采纳。领域写入者负责提交，计算核心返回数据。P/G 以完整日期为原子单元；Features 以完整表或声明的日期窗口为单元，先校验和暂存，再在同一事务内替换。常规刷新保留正式表 OID，以保留视图、权限、索引和触发器的依赖关系。

Features 全量和增量共用目标表级 advisory 事务锁，计算开始前取得。Factors 快照写入使用日期锁，并参与修复排他协议；修复会话覆盖多个日期提交，回滚核对所有权和档案后在一个事务内恢复。禁止自动丢弃其他会话刚提交的结果。

同步数据库会话在拥有它的工作线程内创建、使用并关闭；借用外部连接不会关闭外部管理器。异步调用取消时等待同步工作线程到达安全边界并清理完成，再释放运行资源。连接异常、COPY 异常、提交异常和取消必须保留明确的终态及已提交事实。
