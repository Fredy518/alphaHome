# ADR 001：领域运行契约

状态：采纳。PIT、Factors、Features 和 Fetchers 保留独立协调器。共享 `RunRequest`、不可变 `RunPlan` / `RunUnit`、`SourceBoundary` 和 `RunResult`，不增加一个兼管所有领域的执行器。

请求显式包含领域、任务、模式、日期范围、时区和数据库目标指纹。领域解释自己的模式和依赖；Factors 只展开因子依赖，PIT 就绪检查不会触发 PIT 写入。P v2.0、G v1.1 公式及自然周五规则保持冻结。

计划包含依赖闭包、有效截止日、规模、配置/结构/来源指纹，按规范 JSON 计算 SHA256。生成计划时不写业务表或治理表；入口只负责参数适配与展示。执行必须核对计划哈希和阻断项。计划对象和其嵌套单元不可变，导出的字典是副本。

运行结果区分成功、部分成功、错误、取消、阻断、无工作和预览。`attempted_rows` 与 `committed_rows` 分开；未知提交量保留空值，不用处理量冒充提交量。取消只发生在领域声明的安全边界。
