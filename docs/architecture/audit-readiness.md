# 审计结果与计算就绪状态

审计返回五个维度：结构、日期、来源消费、覆盖和资格。只有各维度均有通过证据时才称为 `healthy`。非空表标为 `available`，不能据此推断来源已刷新；历史审计时间、业务日期、最近执行时间和本次 `audited_at` 分开返回。

真实数据库上的完整审计使用限时 30 秒的只读一致性快照；保存审计记录发生在读取快照结束之后。列表、预览及 `persist=False` 不执行 DDL。治理表缺失时返回 `migration_required`；保存 PIT 审计前缺少审计表会明确报错，不再自动建表。

PIT 尚无可信来源快照消费账本的历史记录标为 `consumption_unverified`。财务输入有缺口时标为 `source_gap`；月份落后和只有结构行的聚合分别显示 `stale`、`structure_only`。不同领域的覆盖分母保持独立，不能把行业实体数当成股票数。

P 的就绪核对按照截止日、近期报告窗口、已转换利润表、可用余额表和当时上市状态确定资格集合。退市、缺主数据、尚未上市、未转换和缺余额表分别统计，只有合资格输入缺失才阻断。该检查不把所有历史原始记录缺口都升级为当前 P 的阻断项。

来源消费使用领域契约明确列出的输入；遗漏实际使用的股票主数据时，审计不会认证完整消费。历史记录不得仅凭运行成功或时间戳相近升级为当前消费证明。
