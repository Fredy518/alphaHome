## 已确定的时间合同

| 字段/选择 | 含义与约束 |
|---|---|
| `ann_date`（PIT 财报） | 该公开版本生效日；正式报告采用 `GREATEST(原 ann_date, COALESCE(f_ann_date, 原 ann_date))`。快报/预告使用自身公告日。 |
| `source_ann_date` / `source_f_ann_date` | 原样保留供应商的初始与实际公告日期；不把修订值放回初始公告日。 |
| `source_update_time` | 供应商/源库最后更新时间，只作来源与同事件选择证据，不能充当第一次采集时间。 |
| 版本键 | `(ts_code, end_date, ann_date, data_source)`。不同生效日保留不同记录。 |
| 同键选择 | 先来源更新时间，再稳定内容指纹；取数、预处理、UPSERT 都不依赖输入或批次到达顺序。 |
| 同日不同来源 | 消费时正式报告优先于快报，快报优先于预告；标准财务指标仅消费 report/express。不同来源原始/PIT 记录保留。 |
| 指标 `ann_date` | 本次观察事件日，事件来自利润表或资产负债表；仅余额表修订也形成新指标记录。 |
| `source_available_date` | 指标或因子实际消费的公开事件日期上界，不得晚于观察/计算日期。指标另存直接利润表和余额表日期。 |
| 合同标记 | `pit_contract_version=public_disclosure_v2`，`availability_basis=public_disclosure_reconstructed`。 |

历史上已经公开、后来才采集的原版，仍能参与公开历史重建，并保留它晚到的来源更新时间。原版晚到不能覆盖更晚公开的修订事件。实际系统当时已持有的回放必须有追加式首次入库/版本账本；当前 `system_asof` 明确拒绝，不能拿 `update_time`、PIT `created_at` 或恢复水位代替。

日期粒度下生效日当天包含该版本。来源缺少盘中/盘后精确发布时间，不能据此断言当天开盘可交易；日期型信号需由交易策略采用明确的下个可执行时点。本轮未改交易执行器。

## 修复与复现

`000928.SZ` 2026Q1 原版 2026-04-28 公开，归母净利 **199100742.14**；修订版 2026-05-09 公开，归母净利 **184563912.14**，两行源 `ann_date` 都是 04-28。旧选择把修订压到 04-28。新取数 SQL、预处理及真实 PostgreSQL UPSERT 验证：04-27 不可得，04-28 至 05-08 为原版，05-09 起为修订；正反输入顺序一致，两次公开事件均保留。另把原版来源更新时间移到 06-30，验证晚采集不改变上述公开日期选择。

季度差分改为逐公开事件选择当时可得的上一季度累计值。例：Q1 原累计 100、09-01 修订为 120，Q2 于 08-08 公告累计 250，当时单季为 150；09-02 快报累计 260 才使用修订基期，单季为 140。缺基期时产生空单季值，不再把累计金额留下来冒充单季。快报归母比例估算、资产负债快照请求的日期键和预告同比基期也约束到各自公告时点。

指标事件取利润表与余额表日期的并集，每只股票每个事件计算一次，并按现有计算器的近两年报告期范围重新生成指标，覆盖其 TTM/同比依赖。余额表同日报告/快报选择显式排序；新观察不会覆盖旧观察。复用计算器时清掉没有来源水位的日期缓存，避免迟到版本重放沿用旧结果。

P/G 查询、计算与持久化携带可得日、合同版本和语义标记。旧行、缺标记、未来来源/观察，以及来源晚于其 P 快照日期均拒绝；不把遗漏旧行解释成已清洁。P/G 原有数值公式和黄金样本结果保持一致，整体输出校验值会因新增元数据和 PostgreSQL NUMERIC 兼容编码而改变；数值公式和数据库实际存值不因校验编码改变。

三张财报 Features 共用版本窗口逻辑：先选同日优先来源与确定性代表行，再对 `(股票, 报告期)` 的不同公开日期做 LEAD。现金流早期版本保留；同日年报与一季报各有独立窗口，不再形成结束日早于开始日的窗口。同一股票/报告期/查询日只匹配一个有效投影版本；查询所有报告期时可匹配多个季度。

Features 的配方指纹和 PostgreSQL 实际 `pg_get_viewdef` 指纹在显式新建时封存到 MV 注释。只读计划、普通刷新、已存在对象的直接 create 都检查该封存。旧 MV 无封存、配方变更或实际 DDL 变更会报告 `migration_required`，不会自动替换旧定义。仅复制旧代码标记不能掩盖实际定义变化。

## 剩余风险与后续范围
