# fundpos 0.4.1 证据位置解耦修复

发布日期：2026-09-14

本版本完成迁入 AlphaHome 后的证据位置切换。证据内容继续按稳定身份与 SHA256 去重，
本地审计位置则在重复导入时更新为当前 AlphaHome 冻结目录，避免数据库中的当前运行仍
引用旧“公募基金行业仓位测算”项目。

主要变化：

- 证据冲突时保留内容身份和首次观察时间，更新审计路径、来源位置及补充元数据；
- 逻辑运行复用时也重新登记运行清单和标准化输入证据；
- 同日同范围的产品成员记录改为引用当前 AlphaHome 运行证据；
- 增加证据身份不可变、审计位置可更新的单元测试；
- 生产输出边界保持不变：AlphaDB `fundpos` schema 是唯一维护与消费层，定时任务不生成
  Excel、HTML 或 JSON 业务报表。

本版本不改变估算模型、基金范围、参数或数值口径。发布后以真实影子运行核对数据库中
当前运行的全部证据路径，并以重复执行验证回填幂等性。
